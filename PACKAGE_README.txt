AgencyOS changed-files overlay

Extract this ZIP into the root of the original/current AgencyOS project and overwrite matching files.
It contains changed and added source/configuration files only; dependencies, build output, local environment files, and credentials are excluded.

No source-file deletion is required when applying this package.

The package adds selectable local or hosted infrastructure, Coolify release gates, cloud-aware object storage, automated migrations, encrypted B2 backups, and 7 daily / 4 weekly / 12 monthly / 1 yearly local Restic retention selection.
Read docs/COOLIFY.md and docs/BACKUP_RECOVERY.md before first deployment.
